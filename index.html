Установка

  1. Скачайте Valhalla_Helper_setup.exe кнопкой выше.
  2. Запустите установщик. Если Windows покажет синее окно «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае» (см. вопросы ниже).
  3. На рабочем столе появится ярлык Valhalla Helper. Запустите игру Viking Rise (клиент для ПК), затем программу.
  4. На вкладке «Дела» отметьте, что делать, и нажмите ▶ СТАРТ. Остановить: клавиша F10 или сдвиньте мышь.

Обновление ставится поверх старой версии — настройки сохраняются. Программа сама сообщит, когда выйдет новая версия.

Безопасность

✔
Не спрашивает и не хранит пароли — в игру входите вы сами.
✔
Никогда не тратит кристаллы и не нажимает платные покупки.
✔
Работает как человек: смотрит на экран и нажимает кнопки. Не подключается к серверам игры напрямую.
✔
Все настройки хранятся только на вашем компьютере.

Использование помощников может противоречить правилам игры. Вы используете программу на свой риск.

Частые вопросы

Windows или антивирус ругается на файл

Программа новая и пока не подписана сертификатом, поэтому SmartScreen её «не знает». Нажмите «Подробнее» → «Выполнить в любом случае». Файл отправлен в Microsoft на проверку.

Программа просит права администратора

Игра запускается от администратора, и без этих прав Windows не даёт программе нажимать кнопки в игре.

Бот ничего не делает / не находит кнопки

Игра должна быть открыта и видна на экране (не свёрнута). На вкладке «Сервис» есть кнопка проверки. Снимки проблемных моментов программа сохраняет в папку debug — пришлите их вместе с файлом bot.log в нашу группу в Telegram.

Как удалить программу

В папке программы есть файл «Удалить Valhalla Helper». Ваши настройки останутся в %APPDATA%\VikingHelper.
